# NeuraMobile Recommender AI

## AI-Based Smartphone Recommendation System

---

## Project Overview

NeuraMobile Recommender AI is a web-based intelligent smartphone recommendation system built using Flask and Python. It suggests smartphones based on user inputs such as budget, RAM, battery capacity, and camera specifications.

The system uses a structured dataset and applies a scoring-based ranking approach to recommend the most suitable mobile phones.

This project demonstrates data filtering, ranking logic, and full-stack web development using Flask.

---

## Key Features

- AI-based smartphone recommendation system  
- Budget and specification-based filtering  
- Smart ranking using custom scoring algorithm  
- Clean and responsive user interface  
- Clickable model links for detailed search  
- Dataset-driven decision making

## System Workflow

1. User enters requirements:
   - Budget
   - RAM
   - Battery capacity
   - Camera quality

2. Dataset is filtered based on constraints

3. AI scoring system evaluates each smartphone based on:
   - Hardware specifications
   - Performance weights
   - Brand influence

4. Smartphones are ranked based on score

5. Top recommendations are displayed to the user
